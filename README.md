# 新闻情感分析

这是一个面向新闻文本情感分析的初始化项目骨架，当前先采用 Python-first 方案，方便后续接入数据采集、标注、建模、评估与推理流程。

## 当前目标

- 搭一个可持续迭代的最小工程结构
- 先完成需求澄清与方案头脑风暴
- 再根据确定后的方案补齐数据流、模型流和评估流

## 目录结构

- `docs/plans/`: 设计文档与阶段性方案
- `src/news_sentiment/`: 项目源码
- `tests/`: 测试
- `data/raw/`: 原始数据
- `data/processed/`: 处理后数据
- `configs/`: 配置文件
- `scripts/`: 任务脚本
